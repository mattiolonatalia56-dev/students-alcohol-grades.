# students-alcohol-grades.
Aim 

This project aim waai to find out  whether students with higher weekend alcohol consumption have lower average final grades. 

Files 

analysis.R: R code for the analysis. 

student-mat.csv: dataset used by the code. 

studenti_alcol_voti_spiegato.tex: report source. 

mean_plus_minus_SE.png: graph showing mean grades with standard error bars. 

mean_plus_minus_SD.png: graph showing mean grades with standard deviation bars. 

Requirements 

R runs the analysis. No additional R packages are needed. 

How to run the code 

Put analysis.R and student-mat.csv in the same folder. 

Open the script in R or RStudio. 

Set the working directory to that folder. In RStudio, select Session > Set Working Directory > To Source File Location. 

Run the complete script from beginning to end. 

Output 

The script creates a folder called risultati containing: 

raw_group_summary.csv 

pdf_transcribed_summary.csv 

raw_vs_pdf_comparison.csv 

The graphs are displayed in R. The script does not save them as image files. 
Data source 

Cortez, P. (2008). Student Performance [Dataset]. 

UCI Machine Learning Repository. 

https://doi.org/10.24432/C5TG7T 

Note 

The analysis is descriptive and does not establish causation. The comparison values from the PDF are entered manually in the R script.
